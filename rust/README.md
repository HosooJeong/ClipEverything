# ClipEverything

Windows x64용 클립보드 보관함이야. Rust와 Windows 네이티브 컨트롤로 버튼판, 검색, 편집 창을 표시해. EXE·포터블·MSI 모두 WebView2 설치 없이 실행할 수 있어.

## 실행

| 파일 | 사용 방식 |
| --- | --- |
| `dist/ClipEverything.exe` | 바로 실행. 기본 프로필은 `%APPDATA%\ClipEverythingRust`야. |
| `dist/ClipEverything.msi` | 설치 폴더와 기본 설정을 선택하고 현재 사용자의 시작 메뉴에 **ClipEverything**를 추가해. |
| `dist/ClipEverything-portable.zip` | 새 폴더에 풀고 실행해. `portable.flag`가 있으면 실행 파일 옆 `portable-data-rust`에 기록을 저장해. |

처음 복사하는 프로그램은 Windows 실행 파일에서 표시 이름과 아이콘을 가져와 왼쪽 사이드바에 등록해. 실행 파일 정보를 확인할 수 없으면 기록된 프로세스명을 사용해. 일반 실행은 프로그램별 사이드바와 클립 그리드를 열고, 자동 시작은 트레이에서 대기해. Esc는 창을 숨겨. ×와 Alt+F4는 **창을 닫으면 트레이에 유지** 설정을 따르고, 트레이 우클릭 메뉴의 **종료**는 프로그램을 끝내.

## MSI 설치 설정

| 항목 | 새 설치 기본값 |
| --- | --- |
| 설치 폴더 | 현재 사용자의 로컬 앱 데이터 아래 `Programs\ClipEverything` |
| 시작 메뉴에 ClipEverything 폴더 만들기 | 켬 |
| 바탕화면에 바로가기 만들기 | 끔 |
| 로그인 시 자동 시작 | 끔 |
| 창을 닫으면 트레이에 유지 | 켬 |
| 선택 영역 등록 / 버튼판 열기 | Ctrl+Alt+C / Ctrl+Alt+V |
| 등록 직후 설명·스크린샷 편집 | 켬 |

시작 메뉴 폴더를 만들면 **모든 앱 → ClipEverything** 아래에 앱 실행과 제거 바로가기가 생겨. 옵션을 끄면 시작 메뉴에는 앱 실행 바로가기만 생겨. 두 경우 모두 설치 폴더의 **Uninstall.exe**를 실행해 제거할 수 있어. 제거 확인창에서 진행하면 Windows Installer가 프로그램과 바로가기를 정리하고, 개인 보관함과 버튼 배치는 유지해.

바탕화면 바로가기는 시작 메뉴 옵션과 별도로 선택할 수 있어. 대화형 최초 설치에서 **마침**을 누르면 버튼판이 바로 열려. 업그레이드·복구·제거·무인 설치 때는 자동으로 열리지 않아.

**충돌 검사**는 Windows에 두 키를 잠시 등록해 본 뒤 바로 해제해. 설치 버튼도 검사하고, 앱을 실행할 때 전역 단축키를 실제로 등록해. 이전 버전이 실행 중이라 같은 키를 점유했다면 트레이에서 종료한 뒤 다시 검사해.

업그레이드 시 기존 설정을 설치창에 먼저 표시해. 설치 폴더를 옮겨도 일반 프로필은 같은 위치를 사용해. 설치할 때 선택한 설정은 설치본의 기본 프로필에 한 번 반영되고 이후에는 앱에서 바꾼 값을 사용해.

- **Ctrl+Alt+C**로 선택한 내용을 등록하면 해당 앱의 버튼판에서 등록 당시 마우스 위치에 가장 가까운 빈칸에 놓여. 꽉 차면 한 행이 늘어나고, 같은 클립을 다시 등록하면 기존 버튼 자리를 유지해.
- **Ctrl+Alt+V**로 현재 앱의 버튼판을 열고 한 번 클릭해 원래 입력 위치에 붙여넣어. 방향키와 Enter로도 선택할 수 있어. Ctrl+F로 선택한 프로그램의 제목·태그를 검색해. 수정·태그·즐겨찾기·삭제는 항목을 우클릭하면 돼.
- 원본 앱 버튼판에서 버튼을 빈칸으로 드래그해 옮기거나, 이미 버튼이 있는 칸에 놓아 두 자리를 바꿔. 오른쪽 가장자리의 **+**는 열을, 아래쪽 가장자리의 **+**는 행을 추가해. 특정 칸을 우클릭하거나 키보드로 선택한 뒤 **Shift+F10**을 눌러 그 위치에 행·열을 삽입하거나 삭제할 수 있어. 버튼이 있는 줄을 지우면 먼저 확인하고, 원본 클립은 보관함에 남아.
- 등록창에서 **이름**을 입력하거나 **영역 캡처**을 눌러 미리보기로 쓸 부분을 드래그해. Esc는 촬영 취소야. 설명을 비우고 이미지만 저장할 수도 있어. 원본 앱 아이콘에 마우스를 올리면 미리보기가 보이고, 붙여넣으면 등록한 원본이 들어가.
- 트레이에서 연 버튼판에서는 버튼을 눌러 클립보드에 복사해. 복사가 끝나면 해당 버튼의 아이콘이 잠깐 체크로 바뀌어. 원하는 창에서 Ctrl+V를 누르면 돼.
- 왼쪽 사이드바에서 프로그램을 바꿔도 창 위치와 크기는 유지돼. 항목이 많으면 페이지를 넘겨 볼 수 있어. 맨 위 화살표를 누르면 이름을 접고 아이콘만 표시해. 다시 누르면 창 왼쪽으로 펼쳐지면서 이름과 개수가 나타나. Windows 애니메이션 효과가 꺼져 있으면 즉시 전환돼. 카테고리가 많으면 사이드바 안에서 스크롤할 수 있어. 검색창 옆의 **− / +**로 버튼 크기를 10단계로 조절해. 아이콘과 제목은 모든 단계에서 함께 표시돼.
- 프로그램별 버튼판 가장자리의 **+**로 행과 열을 추가해. 버튼 크기를 유지한 채 창이 커지고, 화면 크기를 넘으면 이전·다음 페이지로 이동해. 창의 최소 크기는 Windows 배율에 맞춰 적용돼. 단축키와 로그인 시 실행 등은 사이드바 하단의 **설정**에서 바꿀 수 있어.

## 기존 기록

일반 실행의 첫 시작 때 기존 `%APPDATA%\ClipEverything\clips.db`가 있으면 SQLite 백업 API로 별도 프로필에 가져와. WAL에 커밋된 기록과 원본 포맷, 이름, 태그, 즐겨찾기도 함께 옮겨져. 이후 두 앱의 기록은 독립적으로 쌓여. 기존 설정 중 언어, 저장 알림, 복사 후 창 열기를 가져오고, 전역 단축키와 자동 시작은 Rust판 설정을 사용해.

기존 포터블 DB는 새 프로필로 가져올 수 있어.

```powershell
.\ClipEverything.exe --profile "D:\ClipHistory-Rust" --import "D:\ClipHistory\portable-data\clips.db"
```

클립은 로컬 SQLite에 원본 포맷으로 저장돼. DB 자체에는 암호화가 적용되지 않아. 앱이 기록 제외를 요청한 항목은 건너뛰고, 일반 항목은 최근 1,000개를 보관해. 즐겨찾기는 별도로 보존해.

## 개발과 배포

Rust MSVC x64 툴체인, Visual Studio C++ Build Tools, Windows SDK가 필요해. 다음 명령은 이 폴더에서 실행해.

```powershell
cargo run --locked
cargo test --locked --release
cargo clippy --locked --release --all-targets -- -D warnings
.\package.ps1
```

MSI 패키징에는 .NET SDK와 WiX 4를 사용해.

```powershell
dotnet tool install --tool-path target/pack-tools wix --version 4.0.6
.\package.ps1 -Installer
```

- `src/clipboard.rs`에서 Windows 핸들의 소유권과 포맷별 직렬화·복원을 처리해.
- `src/store.rs`에서 기존 DB 가져오기, 원본 포맷, 썸네일, 중복 처리와 보관 정책을 관리해.
- `src/main.rs`와 `src/shell.rs`에서 입력 대상 확인, 트레이, 단축키, 설정과 화면 이벤트를 연결해.
- `src/native_ui.rs`와 `src/native_ui/`에 아이콘 버튼판, 앱 선택, 미리보기, 검색과 설정 화면이 있어.
- `tests/`에 SQLite 회귀 테스트와 별도 Windows 윈도우 스테이션의 클립보드 왕복 테스트가 있어.

## 호환성 확인 범위

Windows에서 전역 단축키로 선택 영역 저장 → 앱별 목록 열기 → 원래 입력창에 붙여넣기를 확인했어. Excel의 2×2 범위는 텍스트·숫자·굵기·셀 배경색을, 한글 2020은 한글 문자열과 굵기를 원본 앱에서 확인했어. 이 PC의 Excel은 외부 클립보드에서 가져온 수식을 값으로 붙여넣는다는 안내를 표시했어. 한글 표, 차트, 매크로 등 복합 개체의 호환성은 추가 검증이 필요해.
